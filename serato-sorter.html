Crates

    Sélectionnez ou créez un crate pour voir son contenu.

    Les crates sont sauvegardés automatiquement dans ce navigateur (localStorage). Pour les utiliser dans Serato DJ Pro : exportez un crate en playlist .m3u8, puis importez-la depuis le panneau Files de Serato (ou glissez le fichier .m3u8 dans un crate). Astuce : gardez tous vos morceaux dans un seul dossier pour que les chemins de fichiers restent valides.

    Limitations actuelles : la lecture des tags (titre/artiste/genre/année/BPM/clé) ne fonctionne que sur les fichiers MP3 (tags ID3). Les autres formats (WAV, AIFF, M4A, FLAC, OGG) peuvent être ajoutés à la liste mais affichent seulement leur nom de fichier.
